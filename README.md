Welcome to my portfolio repository! This single-page application showcases my background, core technical skills, hands-on projects, and contact information.

## 📌 Overview

This lightweight, responsive website acts as a central hub for my professional profile as a Higher Diploma student in Computing & Software Engineering. It features:

* **Header Banner:** Brief intro with primary technical stack tags.
* **About Me:** Concise overview of academic background and focus areas.
* **Skills & Tools:** Visual badges highlighting languages, frameworks, methodologies, and platforms.
* **Featured Projects:** Direct access to repositories for key C++, Java GUI, and Database systems.
* **Contact Information:** Interactive links to reach out directly via Email or GitHub.

## 🛠️ Built With

* **HTML5:** Semantic structure and content organization.
* **CSS3:** Custom styles utilizing Flexbox, CSS variables, hover effects, and responsive breakpoints.
* **Google Fonts:** Integrated `Roboto` font typography.
* **Font Awesome:** Scalable vector icons for project links and contact details.
